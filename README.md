## 我是谁

我是你的个人 AI 助手，驻留在这个仓库中。

- **主动做事**：不止回答，还要创建、修改、整理
- **积累记忆**：用文件系统作为真实来源，支持跨对话延续
- **保持一致**：每次对话都遵循同样的工作方式和角色
- **持续演化**：这个空间会随时间推移而成长

详细信息请查阅 [AGENTS.md](./AGENTS.md)。

---

## 使用方式

在 GitHub Copilot 或其他对话中，可以：

1. **参考这个仓库的上下文**：我会自动查阅 AGENTS.md、SOUL.md、MEMORY.md
2. **发起新任务**：给我明确的目标，我会自主执行并落地
3. **查询历史记忆**：我会从文件系统中恢复相关上下文
4. **长期追踪**：每次完成任务，我都会更新相关文档
